# Chapter 02. 데이터

- **비트**: 컴퓨터가 이해하는 가장 작은 정보 단위
- $n$개의 비트는 $2^n$가지 정보를 표현


## 비트와 바이트

### 비트
- 컴퓨터가 이해하는 가장 작은 정보 단위 ($0$ 또는 $1$)
- **0**: '전기 꺼짐', **1**: '전기 켜짐'으로 해석

### 바이트
- 8개의 비트를 묶은 단위

### 단위 변환
| 단위 | 크기 (용량) |
| :---: | :--- |
| **1 KB** | 1,024 바이트 |
| **1 MB** | 1,024 KB |
| **1 GB** | 1,024 MB |
| **1 TB** | 1,024 GB |


## 이진수 음수 표현

- **2의 보수**: 0, 1로 음수를 표현하는 방식
  - 모든 0과 1을 뒤집고, 거기에 1을 더한 값
- **양수 / 음수 구분**:
  - 하지만 `0101(2)`가 양수면 5, `1011(2)`의 음수일 수도 있다.
  - 똑같이 생긴 것을 구분하는 방법: **플래그(Flag)**
- **이진법의 한계**:
  - 너무 길어져서 십육진법을 사용하기도 함


## 이진수-십육진수 변환

- 십육진수 숫자 하나를 이진수로 표현하려면 **4비트**가 필요
- **변환 방법**: 4개씩 끊기

- **변환 예시**:
  ```text
  11010101(2) = 1101  0101(2) = 13(16)  5(16) = D5(16)
  ```



## 문자 집합

- **문자 집합**: 컴퓨터가 인식하고 표현할 수 있는 문자 모음
- **아스키코드**:
  - 최초의 문자 집합 중 하나
  - 아스키 문자는 **7비트**로 표현 $\rightarrow$ **128개** 문자 표현 가능
  - **한계**: 아스키코드표의 문자 외에는 표현할 수 없다. $\rightarrow$ **유니코드** 사용
